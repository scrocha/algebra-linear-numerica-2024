# Álgebra Linear Numérica — 2024

Repositório das aulas práticas da disciplina de Álgebra Linear Numérica. Os exercícios e implementações estão organizados por aula e usam scripts Scilab (`.sci`).

## Conteúdo

| Diretório | Tópicos |
|---|---|
| [`Aula_Pratica_01`](./Aula_Pratica_01/) | Eliminação de Gauss, pivotamento e fatoração LU para sistemas lineares. |
| [`Aula_Pratica_02`](./Aula_Pratica_02/) | Métodos iterativos de Jacobi e Gauss-Seidel. |
| [`Aula_Pratica_03`](./Aula_Pratica_03/) | Método da potência e método da potência inversa para autovalores. |
| [`Aula_Pratica_04`](./Aula_Pratica_04/) | Classificação com dados de câncer e avaliação por acurácia e matriz de confusão. |
| [`Aula_Pratica_05`](./Aula_Pratica_05/) | Fatoração QR pelos métodos de Gram-Schmidt e Householder e cálculo do espectro. |

Cada pasta reúne os enunciados, scripts `quest_*.sci`, funções auxiliares em `funcs/` e relatórios em PDF.

## Como executar

Abra no Scilab o script `quest_*.sci` da aula desejada. Quando necessário, carregue também as funções auxiliares da pasta `funcs/`. Os PDFs em cada aula trazem os enunciados e relatórios correspondentes.
